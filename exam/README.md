# exam

6개월 커리큘럼 수료 시험 자료 (가상 수강생 시뮬레이션용).

- `learning-objectives.md` · `objectives.json` — 학습 목표 전체 목록 (v6: 채점 대상 681개, 시뮬레이션 수정에서 심화로 내린 89개 표시, 같은 능력은 대표 목표로 합침)
- `blueprint.md` · `blueprint.json` — 시험 설계표 (3부 · 100점 · 목표 ↔ 문항 연결)
- `cleanup-v1.json` — v0 → v1 정리 결정과 이유
- `form-A.md` · `form-B.md` — 문제지 (188문항 × A·B형. 3부는 라이브 실기 15문항 + 포트폴리오 심사 27문항)
- `answer-key-A.md` · `answer-key-B.md` — 모범 답안 · 문항별 10점 채점표 (채점자용)
- `review-ab.md` — 묶음별 검토 결과와 운영 전 확인할 점
- `exam-items.json` — 위 문항 전체 원본 데이터 (3부 문항에는 mode: live/portfolio, block, minutes, evidence_weeks)
- `simulation/` — 기수별 가상 수강생 결과와 그 결과로 고친 커리큘럼 내용 (`cohort-1.md` …), 1~5기 최종 보고 `final-report.md`

목표: 수강생의 **70% 이상이 80점 이상**.

시험 구성: 1부 필기 30점(300분) · 2부 코딩테스트 20점(330분) · 3부 실기 50점 = 라이브 실기 16.9점(720분, AI 금지) + 포트폴리오 심사 33.1점(시험 7일 전 저장소 제출, 구술 40분).

원칙
- 커리큘럼 안의 반복(매주 TIL·Devlog·PR, 같은 유형 코테, 나선형 복습)은 그대로 둔다. 시험에서는 같은 능력을 한 번만 채점한다.
- 시뮬레이션의 학생 에이전트는 이 폴더를 읽지 않는다 (시험 문제 유출 방지).
