## 고친 것 (커리큘럼 v2.6)

영역 담당 4명이 45개를 고쳤다. 검증 담당이 영역마다 다시 확인하고 보정했다.

**과정 전체**
- **일요일 되감기 드릴: 코드 간격 복습** — META에 새 공통 키 rewind(15주)를 넣었다. 단계 마지막 주를 뺀 W05~W23 일요일 복습 카드에 ③ 되감기 드릴 15분이 나온다. 대상은 2~17주 전 코드로, 드릴하지 않던 W07 콤보·판정, W11 Perception, W12 풀·세이브, W13 이동 생성자, W19 테스트가 들어가고 W19는 AI-Off ④ 준비, W23은 누적이다. 4장 AI-Off 표에 행과 「되감기 표」를 넣었고 드릴 하는 법(원본 보는 곳), 2장 주간 리듬, 진화 표(구판은 태그 v0.3.0에서 보기)를 함께 고쳤다. 시간은 같은 카드의 「이번 주 질문」을 전부(25분)에서 ↺·미확인 우선 3개(10분)로 줄여 맞췄다. 나머지 질문은 다음 주 회상 카드 「지난주」 칸에서 다시 나온다. 요일별 문구는 c2-X-summary.js와 페이지 reviewLabel이 같은 규칙으로 만든다.
- **수료 평가 범위·형식 정의 + 수료 대비 주** — 1장에 「수료 평가 — 무엇을 어떻게 보나」 절(HTML 개요 탭 카드)을 새로 넣었다. 네 부분(필기 서술·코드 읽기 / C++ 코테 / 라이브 실기 / 포트폴리오+구술)과 범위(필수 전부, AI 없이), 각 부분을 연습하는 곳을 적었다. 7장에 「수료 대비 주」를 넣었다. 버퍼가 남으면 W24 뒤에 쓰고, 월 필기 모의 → 화 코테 → 수 라이브 실기 모의(부품 3개 무작위) → 목 구술 모의 → 금·토 메우기 → 일 다시 점검 순서다. 버퍼 문구는 2장 표·로드맵 카드·7장에서 'W20 뒤'를 'W24 뒤 수료 대비 주'로 바꿨다. M6 관문 카드(JS)에도 남은 버퍼 안내가 나온다. W23·W24 주차 블록은 C 담당이라 건드리지 않았다.
- **시간 부족·쉼·입문 유형의 핵심 경로** — 2장 「시간이 모자랄 때」를 분량·순서 기준으로 다시 썼다. 줄이는 순서에 ⑤를 더했다(구현은 다음 주가 쓰는 것부터 DoD 첫 줄까지, 나머지는 deferred 이슈로 미루기). 문서는 단계 마지막 주에 몰아서 옮기지 않는다. 「AI로 메우지 않는다」 원칙과 '주 10시간 미만 2주 = 쉼' 규칙(그동안 최소 경로, 관문 점검은 복귀 주로)을 넣었다. 버퍼를 다 쓴 뒤의 「핵심 경로」를 정의하고 7장·현실 체크·🧰 안내 문구(JS)를 거기로 연결했다. 완전 입문자에게는 1장 대상 칸에서 W00 보충 트랙을 안내한다. 보충 주가 C++ 문법에서 막혔으면 첫날 콘솔 실습 30분을 하도록 7장에 넣었다.
- **AI-Off·관문 합격은 과외 세션이 채점** — CLAUDE.md에 「AI-Off 채점 · 관문 채점」 절을 새로 넣었다(명령 표는 그대로). AI-Off는 부품별 시각·코드·빌드 줄을 받고, 채점자가 고른 2줄을 설명해야 합격이다. 관문은 과외 세션이 질문 10개를 골라 핵심어 2/3 기준으로 채점하고(7점 합격), 수료 모의 채점도 같은 방식이다. 결과는 진도 노트에 남긴다. 페이지 JS의 관문 카드는 「설명 능력」을 더 이상 자동 체크하지 않는다. 대신 `W04 관문 채점` 명령과 AI-Off 항목 안내를 보여 주고, AI-Off 힌트 카드에 채점 명령을 넣었다. 4장 규칙·레벨 표 증거 칸, 7장 관문 운영, 평가 탭 안내도 같은 규칙으로 고쳤다. 과외 세션 채점이 혼자 하던 25분을 대신하므로 관문 날 시간은 같다. 챌린지 날만 약 5분 늘어난다.
- **레벨 전환은 결과로 + 골격 모드** — 4장 조정 규칙을 3개로 늘렸다. ① 처음 보는 기술의 첫 이틀은 한 단계 아래 도움을 받는다(L2 주차는 골격 모드, L3 주차는 L2). 예로 W09·W10·W11·W12·W14를 더했다. ③ W09는 AI-Off ②, W17은 AI-Off ③(부품 3/4)을 채점으로 합격하지 못했으면 그 단계 첫 2주를 한 단계 아래 도움으로 한다. 골격 모드는 선언 한 줄과 단계 주석만 받고 본문은 내가 채우는 방식으로 정의했다. CLAUDE.md AI 레벨 절(진도 노트로 전환 확인), 게임 저장소 CLAUDE.md 템플릿(META.claudeMd·9장), 힌트 카드 L2·L3 안내와 프롬프트를 같은 규칙으로 고쳤다.
- **질문 복습 간격: ✓ 3주 만료 + M4부터 수요일 C++ 슬롯** — 페이지 JS pickQ에서 ✓ 표시가 마지막으로 본 지 21일이 넘으면 '모름'과 같은 순위로 다시 나오게 했다. 회상 카드 recallIds는 M4(W13)부터 수요일 '지난 단계' 문항을 C++ 분류에서 뽑는다. 3문항·10분은 그대로라 시간이 늘지 않는다. 2장 주간 리듬, 8장 머리말, 회상 카드 안내 문구를 같은 규칙으로 고쳤다.
- **기록 채널 정리: TS 승격 기준·루브릭 1점·이슈 범위** — 6장 TIL 승격에 TS로 올리는 기준을 넣었다(30분 넘게 걸렸거나 원인이 예상과 달랐던 버그만, 나머지는 TIL 두 줄, 다른 기록에는 TS 링크만). 7장 루브릭에서는 1점 항목을 다음 달 첫 토요일 보충 칸 30분에 '근거 1개'로 보강하게 하고, 두 달 이어지면 다음 관문 「먼저」 맨 앞에 올린다(월요일 드릴 칸은 코드용으로 둔다). 일요일 「다음 주 이슈」(JS issueBlock·6장 표·매주 목록)는 PR을 여는 과제만 이슈로 만든다. 드릴·학습·AI-Off·코테는 이슈를 만들지 않아 10분이 5~10분으로 줄었다. 이 덕분에 X 공통 시간 합이 줄어든다.
- **「미뤄도 되는 것」을 deferred 이슈로 돌려받기** — 7장 관문 운영에 규칙을 넣었다. 미룬 항목은 관문 점검 날 `deferred` 라벨 이슈로 만든다(라벨 만드는 순서 포함). 일요일 「다음 주 이슈」에서 다음 주 과제가 그 항목을 쓰면 그 주 토요일 보충(C) 칸에서 30분 최소판을 먼저 만들고, 시간이 없으면 대체 경로를 PR에 적는다. 일요일 카드(JS issueBlock)와 6장 이슈 정리에 이 확인이 나와서 따로 시간이 들지 않는다. 주차별 관문 블록은 고치지 않고 공통 규칙 한 곳만 고쳤다.
- **영문 에러·주석 읽기 지원(10장)** — 10장 「자주 보는 에러」 표에 8행을 더했다(BindWidget 누락, Accessed None, Unable to bind delegate, AI가 서 있음(NavMesh·Auto Possess AI), BT 키 None, No owning connection, LocalPredicted 발동 실패, 쿠킹 Failed to load). 「엔진 주석·로그에 자주 나오는 영어」 표(25행, GAS·Enhanced Input 용어 포함)를 새로 넣었다. 3장 머리말의 '아는 단어로 추측'을 이 표로 연결했고, CLAUDE.md 영어 규칙도 표를 먼저 보게 바꿨다.
- **Git 따라 하기 설명 보강(.gitattributes·Amend·충돌·브랜치 삭제·대표 기록 링크)** — .gitattributes(META.gitattributes·6장·9장·HTML 받기 버튼·템플릿 복사·pre 5곳)에서 `* text=auto`를 맨 위로 옮기고 줄마다 뜻을 주석으로 달았다. 6장 「망했을 때」 표를 고쳤다. Amend 행에 Force push 이유를 붙였고, '게임 저장소에서 브랜치를 바꾸거나 Pull할 때 에디터 닫기' 행을 새로 넣었다. 위험 버튼 행은 '머지되지 않은 브랜치 삭제'로 좁히고, Merged 브랜치는 지워도 된다고 적었다. 'README 증거 표'는 「대표 기록 링크」로 바꿨다(W13 전에는 월간 회고 루브릭 근거 칸, W13부터는 README 「개발 기록 인덱스」, 마크다운 링크 모양 예시 포함). 6장 표·매주 목록·관문 카드(JS)를 같이 고쳤다.
