## 고친 것 (커리큘럼 v2.5)

영역별 수정안 83개를 겹치는 것끼리 합쳐 82개로 적용했다(과정 전체 13 · W00~W08 21 · W09~W16 23 · W17~W24 25). 적용 후 검증에서 10곳을 더 고쳤다.

**매일·매주 리듬**
- 매일 첫 카드에 🔁 회상 카드 3문항(어제·지난주·지난 단계)을 둔다. 자가 점검·면접 질문과 마찬가지로 소리 내어 답하고 핵심어를 적어야 답이 열린다.
- 매주 월요일 백지 드릴 15~20분: 지난주 핵심 코드를 AI·원본 없이 다시 쓴다(W02~W22, AI-Off 챌린지가 있는 주는 뺌).
- 일요일 복습 카드: 이번 주 질문 + 지난 질문 5개 + 남이 고른 내 코드 3줄 설명 + 다음 주 이슈. 일반 면접 질문 10개는 그 주제를 처음 쓰는 주에 한 번씩 나온다.
- TIL 5분, Devlog는 단계마다 한 번(2주 묶음 · W02·W06·W10·W14·W18·W22), 단계 마지막 주에 월간 회고.
- 필수 분량을 모든 주 20시간 안으로 줄였다(통합 담당 계산 기준).

**관문과 보충 경로**
- 관문에 「설명 능력: 질문 무작위 10개 중 7개」와 「남이 고른 내 코드 3줄 설명」을 넣었다. 단계 마지막 주 일요일의 관문 점검 카드에서 7/10이 되면 자동으로 체크된다.
- 관문마다 「🩹 미달이면」에 먼저 보충할 것과 미뤄도 되는 것을 순서대로 적었다. 크게 미달이면 🧰 보충 주(최대 2주)를 쓰고, 이후 날짜가 7일씩 밀린다.

**AI 사용**
- 4장 AI 레벨 표를 「AI가 주는 것 / 주지 않는 것 / PR에 남길 증거」로 나눴다. PR 본문에 AI 레벨, AI 없이 먼저 쓴 커밋, 리뷰 채택 이유 칸이 생겼다.
- 과외 세션 규칙(`CLAUDE.md`)에 주차별 레벨 표, 레벨을 넘는 요청에 답하는 방식, 막힘 질문 네 칸(에러 원문·멈춘 단계·확인한 것·내 가설), 일요일 주간 점검(`W12 주간 점검: …`)을 넣었다.
- AI-Off ④(W20, 60분)와 ⑤(W23, UE 백지 60분)를 새로 만들었다. ③은 부품별로 채점하고 W14에 재도전한다.

**코딩테스트**
- W05~W16 금요일과 M6 월·수는 예전 문제를 AI 없이 다시 푸는 재풀이 날이다. 힌트를 보고 푼 문제에 💡 체크하면 3일 뒤 재풀이 날에 먼저 나온다.
- 필수 81문제 + 재풀이 15회. 관문 누적 20 → 36 → 52 → 68 → 81. `coding-test/README.md` 표도 다시 만들었다.

**따라 하기 보강**
- W01~W08: 에러 읽기, 포인터·누수·댕글링 실험, virtual 실험, Enhanced Input 설정(모듈·IMC·#include), AnimBP Slot·Build.cs, 콤보·노티파이·Sweep 단계.
- W09~W16: UMG·비동기 로딩, Git 충돌 실습(W09), BT 지연 태스크, 메뉴 흐름·Insights, 패키징, 네트워크 실험 6종, GAS 설정.
- W17~W24: GA 콤보와 HealthComponent → AttributeSet 교체 순서, 측정·회귀 확인, 순수 함수 테스트, 패키징 2단계와 2인 접속, 지원 서류.
- C++ 콘솔 실습(W09 shared_ptr, W13 이동·소멸자·unique_ptr)과 W23 CS 4주제 요약, 10장 「자주 보는 에러」 표와 「Build.cs 모듈」 표.

**범위 조정** — 심화로 내린 학습 목표 12개, 일부만 내리거나 문구를 고친 목표 16개(`learning-objectives.md`의 「v1 → v2 정리 내역」). 대표적으로 엔진 소스 읽기 6개(M1·M2), Primary Asset, 일시정지 메뉴, 리스폰(관전이 기본), Lyra, 적 공격 GA, 크리티컬·풀 반환 테스트, 기술 블로그, PDF 선택 쪽.
